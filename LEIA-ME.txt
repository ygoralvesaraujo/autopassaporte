AUTOPASSAPORTE — LOGIN E RECUPERAÇÃO DE SENHA

Esta versão adiciona:
- Tela de login profissional
- Cadastro de conta com e-mail e senha
- Recuperação de senha por e-mail
- Redefinição de senha por link seguro
- Login/cadastro com conta Google (OAuth)
- Botão Sair
- Dados locais separados por usuário neste dispositivo
- Combustível e câmbio em listas suspensas

IMPORTANTE SOBRE O LOGIN
O login e a recuperação de senha usam Supabase Auth.
Antes de publicar, edite o arquivo supabase-config.js e informe:
- Project URL
- chave anon/public

Nunca coloque a chave service_role no site.

CONFIGURAÇÃO DO SUPABASE
1. Crie uma conta/projeto no Supabase.
2. Em Authentication > Providers, deixe Email habilitado.
3. Se quiser exigir confirmação de e-mail, mantenha Confirm email habilitado.
4. Em Authentication > URL Configuration, coloque a URL do seu GitHub Pages em Site URL.
5. Adicione também a mesma URL em Redirect URLs.
6. Copie Project URL e anon/public key de Project Settings > API para supabase-config.js.

RECUPERAÇÃO DE SENHA
O botão “Esqueci minha senha” envia um e-mail. O link retorna para a página do GitHub Pages e abre a tela de nova senha.

DADOS DO APP
Nesta versão, o login é real, mas os dados de veículos/manutenções ainda ficam no armazenamento local do navegador, separados por usuário. Isso significa que o mesmo usuário ainda não sincroniza os dados automaticamente entre celulares/computadores.
Para a versão comercial com assinatura, backup e acesso em vários dispositivos, o próximo passo é migrar veículos/manutenções/comprovantes para um banco de dados e armazenamento em nuvem.


LOGIN COM GOOGLE
Para ativar o botão “Continuar com Google” no GitHub Pages:
1. No Supabase, abra Authentication > Providers > Google e ative o provedor.
2. Crie/obtenha as credenciais OAuth do Google Cloud para um aplicativo Web.
3. No Google Cloud, adicione a URL de callback do Supabase exibida na tela do provedor Google do Supabase como URI de redirecionamento autorizada.
4. No Supabase, informe Client ID e Client Secret do Google e salve.
5. Em Authentication > URL Configuration, mantenha a URL do seu GitHub Pages em Site URL e também em Redirect URLs.
6. Publique o site no GitHub Pages. Ao clicar em “Continuar com Google”, o usuário será levado ao Google e retornará autenticado ao AutoPassaporte.

IMPORTANTE: a integração do botão já está no código, mas o login Google depende da ativação/configuração do provedor Google no seu projeto Supabase. Nunca coloque Client Secret do Google ou service_role do Supabase no código do site.
