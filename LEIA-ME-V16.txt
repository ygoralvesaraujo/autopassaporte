# AutoPassaporte V16 — Supabase

## 1. Criar as tabelas
No Supabase: SQL Editor → New query → cole o conteúdo de `SUPABASE_V16.sql` → Run.

## 2. Publicar
Substitua os arquivos da versão anterior no GitHub Pages, mantendo `index.html`, `supabase-config.js`, `manifest.webmanifest` e `assets/` na raiz do repositório.

## 3. O que esta versão salva na nuvem
- veículos
- manutenções
- edição/exclusão de veículos
- edição/exclusão de manutenções
- quilometragem atualizada pelo último registro

Cada usuário só consegue consultar e alterar seus próprios dados por causa do RLS.

## 4. Comprovantes
Nesta V16, os dados do veículo e da manutenção já ficam na nuvem, mas o conteúdo dos arquivos anexados ainda não foi migrado para o Storage. O arquivo continua sendo lido localmente enquanto a página está aberta. A próxima etapa pode usar Supabase Storage para salvar os comprovantes na nuvem.
